Personal Portfolio Website 🌐

📌 Overview

This project is a personal portfolio website built with HTML, CSS, and JavaScript.
It showcases personal information, skills, courses, education, services, and a gallery of my city.
The website also includes a contact form integrated with Google Sheets and a login/sign-up form.

🚀 Features

🎨 Responsive Design – Works on desktop and mobile

🏷️ About Section – Personal details, skills, courses, education

💼 Services Section – Showcasing web design and programming skills

🏙️ City Section – Gallery with hover effects and descriptions

📩 Contact Section – Contact form connected to Google Sheets + social media links

🔐 Login/Sign Up Form – Toggle between sign-in and sign-up

📱 Mobile Menu – Responsive navigation with open/close functionality

⚙️ Technologies Used

HTML5

CSS3

JavaScript (Vanilla JS)

Font Awesome (icons)

Google Apps Script (form handling to Google Sheets)
